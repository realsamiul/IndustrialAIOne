Analysis Pipeline

  • Sensor Fusion

    PZEM-004T + ESP32. Polling Voltage, Current, Power Factor at 1Hz. Non-invasive CT clamp installation.

  • Algorithmic Core

    TS2Vec + MOMEMTO. A universal time-series framework with a memory gate to handle "concept drift" over months of operation.

  • Change Point Detection

    Bayesian CPD (Ruptures). Identifies structural changes in consumption to trigger "Peak Shaving" alerts.

class PowerMonitor: def __enter__(self): # Load TS2Vec Model with Memory Gate self.ts2vec = TS2Vec(input_dims=1, output_dims=64) def analyze_stream(self, readings): # 1. Vectorize Data Stream vec = self.ts2vec.encode(readings) # 2. Reconstruct & Calc Error (Anomaly Detection) reconstruction = vec.mean() error = (readings - reconstruction) ** 2 # 3. Bayesian Change Point Detection (PELT) bkpts = rpt.Pelt(model="rbf").fit(error).predict(pen=3) # 4. Determine Grid Status (Peak vs Off-Peak) is_peak = 17 <= datetime.now().hour <= 23 return { "surge_detected": error[-1] > 2.5 * error.mean(), "action": "ACTIVATE_GENERATOR" if is_peak else "MONITOR" }

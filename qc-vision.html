QC Vision

Real-time fabric defect detection running on commodity edge hardware.
75ms Inference. 92% F1 Score.

The Leakage

RMG factories in Bangladesh lose 3-5% of total yardage to defects like oil stains, needle holes, and misprints. Current solutions are polarized: manual inspection (slow, error-prone) or imported AOI rigs (KeyeTech/Kevision) that cost >$12,000 and are hardware-locked.

Edge Architecture

  • Backbone Model

    MicroViT-Tiny-Q8 (Quantized). 9M parameters. Replaced DINO-v2-Small for 3.6x speedup on CPU.

  • Segmentation

    PicoSAM-2. Promptable mask generation allows "Human-in-the-Loop" labeling by QA managers.

  • Deployment

    Served via Modal.com Functions (FastAPI ASGI) with auto-scale-to-zero.

Preprocess img = Image.open(io.BytesIO(jpg_bytes)).convert("RGB") arr = np.array(img.resize((224, 224))).astype(np.float32) / 255 # 2. Vision Transformer Feature Extraction feat = self.vit.run(None, {"input": arr})[0] # 3. Generate Defect Mask mask = self.sam.run(None, { "image_embeddings": feat, "point_coords": np.zeros((1, 1, 2), np.float32) })[0][0] return { "defect": bool(mask.mean() > 0.07), "mask_b64": encode_mask(mask) }

QC Vision

Real-time fabric defect detection on commodity edge hardware.
28ms Inference. 92% F1 Score.

Frugal Innovation

Fig 2: Recycled Android Smartphone as Vision Sensor (Zero-CAPEX model)

The Leakage: RMG factories in Bangladesh lose 3-5% of total yardage to defects like oil stains, slubs, and misprints. Current market options are binary: slow manual inspection or imported AOI rigs (KeyeTech/Kevision) that cost >$12,000 and are hardware-locked.

The Disruption: By utilizing recycled Android smartphones (Snapdragon 778G+ processors) as vision sensors, we lower the CAPEX from $12,000 to ~$150. We process locally to ensure data sovereignty and zero latency.

Annual Loss $390M

The Technical Stack

  • Backbone Model

    MicroViT-Tiny-Q8 (Quantized). We utilize 8-bit integer quantization to run Vision Transformers on CPUs. This replaces heavy DINO-v2 models, achieving a 3.6x speedup (28ms per frame) while maintaining F1 scores within -1 point on MVTec AD v2 fabric datasets.

  • Zero-Shot Segmentation

    PicoSAM-2. Enables "Human-in-the-Loop" workflow. A QA manager can tap a defect on the tablet, and the model instantly "snaps" a mask to it, refining the dataset locally without needing a data scientist.

  • Privacy & Logs

    All imagery is processed in RAM. Only the metadata (defect class, timestamp, coordinates) is logged to a local DuckDB instance for generating EU Digital Product Passports (DPP). 

@app.cls(gpu="T4")
class DefectDetector:
    def __enter__(self):
        # Load 8-bit Quantized ONNX Weights
        vit_path = hf_download("ai-one/microvit-cloth-q8")
        self.vit = ort.InferenceSession(vit_path)
        
        # Hybrid: YOLOv8 Nano for classification + SAM for Mask
        self.yolo = YOLO("/models/yolov8n-fabric.pt")

    def detect(self, img_array):
        results = self.yolo(img_array)
        grade = "A"
        
        for r in results:
            # Economic logic: Reject roll if Critical
            severity = self.severity_map.get(r.defect_type)
            if severity == "critical":
                grade = "D" 
                
        return {
            "quality_grade": grade,
            "export_eligible": grade in ["A", "B"],
            "loss_usd": self.calc_loss(grade)
        }

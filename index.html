Module 01

QC Vision

The Problem: Manual inspection misses 3-5% of defects.
The Solution: We don't stream video to the cloud. We run MicroViT-Tiny-Q8 backbones directly on the device (Raspberry Pi 5 / Android).

Tech Stack: MicroViT, PicoSAM-2, ONNX Runtime (Int8 Quantization). 

class DefectDetector:
    def __enter__(self):
        # Load DINO-v2 / MicroViT optimized for Edge
        self.vit = ort.InferenceSession(vit_path, providers=["CUDAExecutionProvider"])
        self.sam = ort.InferenceSession(sam_path, providers=["CUDAExecutionProvider"])

    def predict(self, jpg_bytes):
        # 1. Preprocess & Feature Extraction
        arr = self.preprocess(jpg_bytes)
        feat = self.vit.run(None, {"input": arr})[0]
        
        # 2. Zero-Shot Segmentation (PicoSAM)
        mask = self.sam.run(None, {"image_embeddings": feat})
        
        # 3. Decision Logic (Bangladeshi Cotton Standards)
        return {"defect": mask.mean() > 0.07}
                                    
class PowerMonitor:
    def analyze_power(self, readings):
        # 1. Vectorize Time-Series (TS2Vec)
        vec = self.ts2vec.encode(readings)
        
        # 2. MOMEMTO Patch for Concept Drift
        if self.drift_detected(vec):
            self.update_memory_gate(vec)

        # 3. Bayesian Change Point Detection
        bkpts = rpt.Pelt(model="rbf").fit(vec).predict(pen=3)
        
        return {
            "anomalies": len(bkpts),
            "cost_usd": self.calc_tariff(readings, grid="PEAK")
        }

Module 03

FailPredict

The Ear. Listening to the heartbeat of the machine to predict a heart attack 5 hours before it happens.

Vibration analysis using GRU-128 neural networks trained on NASA CMAPSS data, adapted for Juki sewing heads.

  • Green: RUL > 4 hours
  • Red: RUL < 1 hour (Critical Stop)
def predict_failure(self, sensor_data):
    # Vibration (X,Y,Z) -> Feature Extraction
    vib_features = self.extract_spectral(sensor_data)
    
    # GRU-128 Inference for RUL (Remaining Useful Life)
    rul_hours = self.gru_model(vib_features)
    
    # Physics-Informed Constraints (Pi-Transformer)
    rul_hours = self.apply_physics_constraints(rul_hours)

    return {
        "rul_hours": round(rul_hours, 1),
        "action": "MAINTAIN_NOW" if rul_hours < 4 else "MONITOR"
    }

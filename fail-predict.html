Inference Pipeline

  • Vibration Sensing

    MPU-6050 Accelerometer. Captures X, Y, Z axis acceleration to detect harmonics associated with bearing wear.

  • Neural Core

    GRU-128 (Gated Recurrent Unit). Trained on NASA CMAPSS jet engine data, transfer-learned for textile sewing heads.

  • Constraint Layer

    Pi-Transformer. Physics-informed layer that constrains predictions based on mechanical realities (friction/heat). 

def predict_rul(sensor_data):
    # 1. Load Pretrained GRU Model (NASA CMAPSS)
    model = torch.load("models/gru_rul.pt")
    
    # 2. Extract Spectral Features (FFT)
    vib_features = extract_features(sensor_data['vibration'])
    
    # 3. Predict Remaining Useful Life (RUL)
    rul_cycles = model(torch.from_numpy(vib_features))
    rul_hours = rul_cycles * 0.083
    
    # 4. Traffic Light Logic
    if rul_hours < 1:
        status = "CRITICAL_STOP"
    elif rul_hours < 4:
        status = "WARNING_MAINTAIN_SOON"
    else:
        status = "NORMAL"
        
    return {"rul_hours": round(rul_hours, 2), "status": status}
